## Overview
This skill defines the master operating framework for conducting data science, machine learning, and deep learning laboratory assignments as a closed-loop analytical harness.

## Core Principle
Continuous closed-loop engineering:
```
INSPECT → UNDERSTAND → PLAN → ACT → OBSERVE → VERIFY → REFINE → REPEAT
```

## Key Rules
1. **1–2 Line Step Rationales:** Citing exact prior code outputs before taking any coding action.
2. **Student-Friendly Technical Voice:** Precise technical terms without jargon density, emojis, or analogies.
3. **Evidence-Based Observations:** Structured as `Observation → Interpretation → Decision` using exact statistical numbers and visual plot evidence.
4. **Lab Inquiry Answers:** Structured as `ANSWER → EVIDENCE → REASON → IMPLICATION` to be 100% defendable in a viva.
5. **No Fabrication or Mathematical Overkill:** Zero assumed metrics or unnecessary derivations.
