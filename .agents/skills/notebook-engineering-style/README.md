## Overview
A comprehensive technical specification for writing, structuring, modularizing, and explaining Python machine learning notebooks cleanly, simply, and dataset-aware.

## Core Pillars
1. **Readable & Simple:** Minimal abstractions, explicit variable names, and no premature over-engineering.
2. **Dataset-Aware:** Preprocessing, scalers, and layer dimensions directly motivated by observed data shapes and distributions.
3. **PEP 8 Code Architecture:** Standard 4-space indentation, max 79 characters per line, max 30 lines per cell.
4. **Natural Explanations:** 1–2 line step rationales without generic AI fluff, analogies, or emojis.
