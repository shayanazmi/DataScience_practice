## Overview
A specialized skill for writing precise, technical, and data-grounded post-cell observations in machine learning notebooks.

## Formula
```
[Exact Numbers / Visible Patterns] + [Causal Dataset/Model Mechanism] + [Downstream Experimental Impact]
```

## When to Apply
Insert an **Observation** markdown block immediately following any cell producing:
- Metric summaries, classification reports, or benchmark tables.
- Scatter plots, distribution charts, PCA / t-SNE manifold projections.
- Training loss and accuracy learning curves.
- Normalized confusion matrix heatmaps and multi-model ROC curves.
