# Agent-Reach Research & Internet Data Retrieval Rule

## Capabilities & Usage
When conducting research, investigating libraries, retrieving web content, scraping discussions, or gathering internet intelligence:
1. **Tool Invocation**: Use the globally installed `agent-reach` CLI tool or its underlying parsers.
2. **Supported Modalities**:
   - **Web Articles & Documentation**: Use Jina Reader (`curl -s https://r.jina.ai/<URL>`) or `agent-reach` for clean markdown extraction.
   - **YouTube Subtitles & Transcripts**: Use `yt-dlp` or `agent-reach` to pull video transcripts and metadata.
   - **Feeds & Forums**: Extract RSS/Atom feeds, V2EX discussions, Reddit posts, and developer communities.
3. **Research Integrity**: Ground technical solutions in extracted real-time web facts and cite the source URLs accurately.
